# NHK News Easy Backend

## Project Overview
This project is a Go-based backend API for NHK News Easy. It is organized for maintainability, testability, and high code coverage.

## Code Structure
```
cmd/
  api/
    main.go         # API entry point
    main_test.go    # Tests for main.go
internal/
  config/
    paths.go        # Project root and log path detection
    paths_test.go   # Tests for config/paths.go
  db/               # Database logic (if any)
  graphql/          # GraphQL logic (if any)
  service/

    links_test.go   # Tests for service/links.go
  util/

    logger_test.go  # Tests for util/logger.go
  worker/           # Background jobs (if any)
logs/

.env                # Environment variables
```

## Code Flow
- **main.go**: Entry point. Loads environment variables, sets up logging, and starts the API server.
- **SetupEnv**: Loads `.env` and sets default `HOST` and `PORT` if not present.
- **SetupLogger**: Initializes logger and logs warnings if `.env` is missing.
- **StartServer**: Starts the HTTP server with `/links` endpoint.
- **Logger Utility**: Writes logs to `logs/log.txt` in the project root.
- **Handlers**: Business logic is separated into service files (e.g., `links.go`).

## Testing
- All major components have corresponding test files.
- Tests cover normal and error paths, including environment, logging, and server logic.
- Mocking is used for server logic to achieve maximum coverage.
- Coverage is maximized except for the `os.Exit` line in `main()` (not coverable in Go).

## Running Tests and Coverage
To run all tests and generate a coverage report:

```bash
go test -coverprofile=coverage.out ./...
go tool cover -func coverage.out   # Function-level coverage breakdown
go tool cover -html coverage.out   # Open HTML coverage report
```
Or use the provided script:

```bash
bash test_coverage.sh
```

## Notes
- The `os.Exit` line in `main()` will always show as uncovered; this is normal in Go.
- All other logic is covered by tests.
- Ensure Go is in your PATH when running scripts in Bash.
